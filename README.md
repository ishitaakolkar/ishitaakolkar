<div align="center"><sup>✦ &nbsp; <code>whoami</code> &nbsp; ✦</sup></div>

<br>

I'm an **Applied GenAI Engineer** at **AtliQ Technologies** — the kind who's happier when a model is in production arguing with real users than when it's sitting pretty in a notebook with a 0.99 val-accuracy and zero self-awareness.

I build systems where **LLMs meet backend engineering meet actual product thinking.** Voice agents that interrupt politely. Retrieval that retrieves the *right* thing. Models that, when they're wrong, can at least tell you *why* — because I find "it works, don't ask" to be a deeply unsatisfying design philosophy.

```python
class Ishita(Engineer):
    role        = "Applied GenAI Engineer @ AtliQ"
    location    = "Ahmedabad, IN"  # UTC+5:30, mostly caffeinated
    focus       = ["voice ai", "agentic systems", "hybrid retrieval", "explainability"]

    def ship(self, idea: Idea) -> Product:
        assert idea.is_messy, "clean ideas are suspicious and usually already solved"
        while not deployed(idea):
            idea = self.iterate(idea)      # the fun part
            self.argue_with(self.model)    # character-building
        return idea.deploy()               # the whole point

    def __repr__(self):
        return "writes prompts defensively, like the model is out to get her"
```

> <sub>I like turning messy ideas into working systems · I trust deployed AI over demo AI · and I'm fairly sure the future belongs to engineers who ship, not just the ones who train.</sub>
